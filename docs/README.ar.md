# UnfocusMute

[한국어](../README.md) | [English](../README_en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Português](README.pt.md) | [हिन्दी](README.hi.md) | العربية

UnfocusMute تطبيق صغير وخفيف لعلبة نظام Windows. يكتم تلقائيًا صوت الألعاب أو التطبيقات التي تختارها عندما تنتقل إلى الخلفية.

يبلغ حجم ملف Windows التنفيذي في الإصدار الحالي نحو 676KB، أي أقل من 1MB، لذلك يبقى تنزيله وتشغيله كأداة محمولة خفيفًا.

التطبيق مبني بلغة Rust ويُوزَّع كتطبيق محمول. لا يتحكم إلا في جلسات الصوت التي تسجلها. عندما يعود التطبيق إلى المقدمة، يعيد UnfocusMute صوت الجلسات التي كتمها بنفسه فقط، ولا يغير أي كتم قمت به يدويًا.

يكون مفيدًا خصوصًا عند الانتقال من لعبة إلى متصفح أو تطبيق محادثة أو نافذة عمل باستخدام Alt+Tab. يمكنك إبقاء تطبيق واحد في الخلفية صامتًا دون فتح مزج الصوت في Windows مرارًا.

## المزايا الأساسية

- يدعم التسجيل حسب ملف `.exe` أو حسب PID فردي.
- يمكنه تجميع عدة عمليات من نفس الملف التنفيذي عند الحاجة.
- يتيح تسجيل نسخة عملية محددة عبر `إظهار تفاصيل PID`.
- يعيد الصوت فقط للجلسات التي كتمها UnfocusMute، ويحافظ على الكتم اليدوي.
- يعمل كتطبيق محمول من ملف ZIP دون مثبت.

## مناسب لـ

- الانتقال المتكرر من لعبة أو تطبيق إلى نافذة أخرى باستخدام Alt+Tab
- الألعاب التي تحتاج إلى كتم في الخلفية
- الألعاب التي لا توفر خيار كتم تلقائي عند الانتقال إلى الخلفية
- كتم صوت لعبة في الخلفية مع إبقاء المتصفح أو تطبيق المكالمات مسموعًا
- إدارة تطبيق كامل حسب `.exe` أو التحكم في PID محدد فقط

## الميزات

- يكتم تلقائيًا التطبيقات المسجلة فقط عندما لا تكون في المقدمة.
- يعيد الصوت فقط للجلسات التي كتمها UnfocusMute.
- إضافة الأهداف من قائمة التطبيقات قيد التشغيل أو بكتابة اسم تنفيذي مثل `game.exe`.
- يدعم التسجيل المجمع حسب `.exe` والتسجيل حسب PID.
- يعمل من علبة النظام مع الإيقاف المؤقت، واختصار مجلد الإعدادات، ومنع تشغيل أكثر من نسخة.
- اختيار اللغة عند أول تشغيل والتبديل الفوري داخل التطبيق بين English و한국어 و日本語 و简体中文 وEspañol وFrançais وPortuguês وहिन्दी والعربية.
- الإعدادات محفوظة محليًا في `%APPDATA%\UnfocusMute\config.json`.

## لماذا Rust

UnfocusMute أداة صغيرة تعمل في الخلفية، لذلك تهم سرعة التشغيل واستهلاك الذاكرة وسهولة التوزيع. الملف التنفيذي الأصلي المبني بـ Rust يعمل دون runtime منفصل ويتكامل مباشرة مع Windows CoreAudio APIs دون إطار عمل مقيم غير ضروري.

## الأمان والخصوصية

يعمل UnfocusMute بأسلوب محلي أولًا. يحفظ محليًا أسماء العمليات المسجلة، وPID الاختيارية، ولغة الواجهة، وموضع النافذة، وتفضيلات بدء التشغيل فقط.

يتم اكتشاف جلسات الصوت والتحكم في الكتم على جهازك عبر Windows CoreAudio APIs. لا توجد طلبات شبكة أو حسابات أو قياسات استخدام أو تحليلات أو تقارير أعطال أو تسجيل بعيد أو ملفات سجل منفصلة.

## التنزيل والتشغيل

نزّل ملف ZIP الخاص بـ Windows 10/11، ثم فك الضغط وشغّل `UnfocusMute.exe`. التطبيق محمول، لذلك لا يحتاج إلى مثبت ولا يتطلب runtime منفصلًا أو Rust أو Visual Studio Build Tools أو MinGW.

## الاستخدام

1. شغّل UnfocusMute.
2. اختر اللغة عند أول تشغيل. اللغة الافتراضية هي English.
3. افتح اللعبة أو التطبيق الذي تريد إدارته.
4. حدّث قائمة التطبيقات قيد التشغيل، اختر عنصرًا، ثم اضغط `إضافة المحدد`.
5. يتم تجميع العناصر التي لها نفس `.exe` افتراضيًا.
6. استخدم `إظهار تفاصيل PID` فقط عندما تحتاج إلى تسجيل نسخة عملية محددة.
7. إغلاق النافذة يبقي UnfocusMute يعمل في علبة النظام. استخدم `خروج` للإغلاق الكامل.

## الإعدادات الافتراضية

عند أول تشغيل، يمكنك اختيار ما إذا كان UnfocusMute يبدأ تلقائيًا عند تسجيل الدخول إلى Windows. في الإعدادات الجديدة، يكون التشغيل التلقائي معطلًا افتراضيًا، بينما يكون البدء مصغرًا في علبة النظام وإلغاء كتم التطبيقات عند الخروج مفعّلين.

اضغط `اللغة` داخل التطبيق للتبديل فورًا بين English و한국어 و日本語 و简体中文 وEspañol وFrançais وPortuguês وहिन्दी والعربية. يتم حفظ الاختيار تلقائيًا.

## بناء المطورين

هدف الإصدار الموصى به هو `x86_64-pc-windows-msvc`.

```powershell
rustup target add x86_64-pc-windows-msvc
cargo build --release --target x86_64-pc-windows-msvc
```

إنشاء ZIP للتوزيع:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

يتم إنشاء الحزمة في `dist\UnfocusMute-<version>-windows-x64.zip` وتتضمن الملف التنفيذي و`LICENSE` و`THIRD_PARTY_NOTICES.md` و`README_ko.md` و`README_en.md` في الجذر، وبقية الوثائق المترجمة داخل `docs`.
