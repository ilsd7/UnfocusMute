UnfocusMute تطبيق صغير وخفيف لعلبة نظام Windows يكتم صوت اللعبة أو التطبيق الذي تختاره فقط عندما ينتقل إلى الخلفية.

لأنه مبني كتطبيق Rust أصلي، يعمل مباشرة دون runtime منفصل. حجم ملف Windows التنفيذي الحالي نحو 477KB، أي أقل من 1MB.

<p align="center">
  <img src="../assets/screenshot.png" alt="نافذة تطبيق UnfocusMute" width="760" loading="lazy" decoding="async">
</p>

سجّل التطبيقات التي تريد إدارتها؛ عندما لا تكون في المقدمة، يكتم UnfocusMute جلسات الصوت الخاصة بها فقط. وعندما يعود التطبيق إلى المقدمة، يعيد UnfocusMute صوت الجلسات التي كتمها بنفسه فقط، ولا يغيّر أي كتم قمت به يدويًا.

يكون مفيدًا خصوصًا عند الانتقال من لعبة إلى متصفح أو تطبيق محادثة أو نافذة عمل باستخدام Alt+Tab. يمكنك التحكم في صوت الخلفية دون فتح مزج الصوت في Windows مرارًا.

---

## التنزيل والتشغيل

نزّل ملف ZIP الخاص بـ Windows 10/11 من [GitHub Releases](https://github.com/ilsd7/UnfocusMute/releases)، ثم فك الضغط وشغّل `UnfocusMute.exe`. التطبيق محمول، لذلك لا يحتاج إلى مثبت ولا يتطلب runtime منفصلًا أو Rust أو Visual Studio Build Tools أو MinGW.

## الاستخدام

1. شغّل UnfocusMute.
2. اختر اللغة عند أول تشغيل. اللغة الافتراضية هي English.
3. افتح اللعبة أو التطبيق الذي تريد إدارته.
4. حدّث قائمة التطبيقات قيد التشغيل، اختر عنصرًا، ثم اضغط `إضافة المحدد`.
5. استخدم `إظهار تفاصيل PID` فقط عندما تحتاج إلى تسجيل نسخة عملية محددة. الهدف المسجّل بواسطة PID ينطبق فقط على النسخة الحالية؛ إذا أُعيد تشغيل التطبيق وتغيّر PID، فاختره من جديد.
6. إغلاق النافذة يبقي UnfocusMute يعمل في علبة النظام. استخدم `خروج` للإغلاق الكامل.

## معرفة اسم ملف تشغيل اللعبة

إذا لم تكن متأكدًا مما يجب كتابته، فتحقق في مدير المهام من اسم ملف التشغيل الذي ينتهي بـ `.exe`.

1. شغّل اللعبة أولًا.
2. استخدم `Alt`+`Tab` أو `Windows`+`Tab` للخروج من شاشة اللعبة والعودة إلى Windows.
3. اضغط `Ctrl`+`Shift`+`Esc` لفتح مدير المهام.
4. رتّب قائمة العمليات حسب `CPU` للعثور على اللعبة التي شغّلتها للتو.
5. انقر بزر الماوس الأيمن على اللعبة وافتح `خصائص`.
6. ابحث عن اسم ملف التشغيل الذي ينتهي بـ `.exe` مثل `game.exe`، ثم أضفه إلى UnfocusMute.

## المزايا

- يؤتمت كتم الصوت في الخلفية لكل لعبة أو تطبيق، بحيث يتبع الصوت تغيّر التركيز دون ضبط يدوي.
- يعيد فقط الصوت الذي غيّره UnfocusMute ويحافظ على أي كتم يدوي.
- يبقى أداة خفيفة ومحمولة ومحلية، دون تثبيت أو حساب أو اتصال شبكة.

## مناسب لـ

- الانتقال المتكرر من لعبة أو تطبيق إلى نافذة أخرى باستخدام Alt+Tab
- الألعاب التي لا توفر خيار كتم تلقائي عند الانتقال إلى الخلفية
- كتم صوت لعبة في الخلفية مع إبقاء المتصفح أو تطبيق المكالمات مسموعًا
- عندما يفتح التطبيق عدة عمليات من نفس `.exe` وتحتاج إلى التبديل بين إدارة التطبيق كاملًا والتحكم في PID محدد

## الميزات

- يكتم جلسات الصوت للتطبيقات المسجلة تلقائيًا عندما تكون في الخلفية، ويعيدها عند الرجوع إلى المقدمة.
- يتيح إضافة الأهداف من قائمة التطبيقات قيد التشغيل أو بكتابة اسم تنفيذي مثل `game.exe`.
- يدعم أهداف `.exe`، وأهداف PID للنسخة الحالية، وخيار `إظهار تفاصيل PID`.
- يبقى في علبة النظام، مع الإيقاف المؤقت، وفتح مجلد الإعدادات، ومنع تشغيل أكثر من نسخة.
- يتيح اختيار اللغة عند أول تشغيل، ثم التبديل داخل التطبيق بين English و한국어 و日本語 و简体中文 وEspañol وFrançais وPortuguês وहिन्दी والعربية.
- الإعدادات محفوظة محليًا في `%APPDATA%\UnfocusMute\config.json`.

## ملاحظات قبل الاستخدام

لا يحقن UnfocusMute أي كود داخل الألعاب، ولا يقرأ ذاكرة اللعبة، ولا يعترض الإدخال، ولا يغيّر ملفات اللعبة. وبما أنه يستخدم فقط معلومات العمليات/النافذة الأمامية في Windows وتحكم كتم جلسات CoreAudio، فمن المتوقع ألا يسبب مشكلات مع معظم أنظمة مكافحة الغش، لكن لا يمكن ضمان التوافق مع جميعها.

## الأمان والخصوصية

يعمل UnfocusMute بأسلوب محلي أولًا. يحفظ محليًا أسماء العمليات المسجلة، وPID الاختيارية، ولغة الواجهة، وموضع النافذة، وتفضيلات بدء التشغيل فقط.

يتم اكتشاف جلسات الصوت والتحكم في الكتم على جهازك عبر Windows CoreAudio APIs. لا توجد طلبات شبكة أو حسابات أو قياسات استخدام أو تحليلات أو تقارير أعطال أو تسجيل بعيد، ولا ينشئ التطبيق ملفات سجل منفصلة.

## الإعدادات الأولية

عند أول تشغيل، يمكنك اختيار ما إذا كان UnfocusMute يبدأ تلقائيًا عند تسجيل الدخول إلى Windows. في الإعدادات الجديدة، يكون التشغيل التلقائي معطلًا افتراضيًا، بينما يكون البدء مصغرًا في علبة النظام وإلغاء كتم التطبيقات عند الخروج مفعّلين.

اضغط `اللغة` داخل التطبيق للتبديل فورًا بين English و한국어 و日本語 و简体中文 وEspañol وFrançais وPortuguês وहिन्दी والعربية. يتم حفظ الاختيار تلقائيًا.

استخدم `فتح مجلد الإعدادات` داخل التطبيق إذا احتجت إلى فحص ملف الإعدادات مباشرة أو إدارة ملفات النسخ الاحتياطي.

## البناء من المصدر

هدف الإصدار الموصى به هو `x86_64-pc-windows-msvc`.

المتطلبات:

- Rust stable
- Visual Studio Build Tools 2022 أو Visual Studio 2022
- Windows 10/11 SDK

```powershell
rustup target add x86_64-pc-windows-msvc
cargo build --release --target x86_64-pc-windows-msvc --locked
```

تم ضبط إصدارات release لتقليل حجم الناتج. يستخدم release profile في `Cargo.toml` إزالة الرموز، وLTO، ووحدة codegen واحدة، و`panic = "abort"`، وتحسينًا يفضّل الحجم.

الملف التنفيذي:

```text
target\x86_64-pc-windows-msvc\release\unfocusmute.exe
```

إنشاء ZIP للتوزيع:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

تحديث إشعارات تراخيص الأطراف الثالثة:

```powershell
cargo about generate about.hbs -c about.toml --locked --offline -o THIRD_PARTY_NOTICES.md
```

يتم إنشاء الحزمة في `dist\UnfocusMute-<version>-windows-x64.zip`، ويتم إنشاء ملف تحقق SHA-256 في `dist\UnfocusMute-<version>-windows-x64.zip.sha256`. يتضمن ملف ZIP الملف التنفيذي و`LICENSE` و`THIRD_PARTY_NOTICES.md` و`README_ko.md` و`README_en.md` في الجذر، وبقية الوثائق المترجمة داخل `docs`.
